The following short program computes the first few prime numbers with the sieve of Eratosthenes and prints the running total of their sum. It is written in Python.

def primes_below(limit):
    sieve = [True] * limit
    sieve[0:2] = [False, False]
    for n in range(2, int(limit ** 0.5) + 1):
        if sieve[n]:
            for multiple in range(n * n, limit, n):
                sieve[multiple] = False
    return [n for n, is_prime in enumerate(sieve) if is_prime]

total = 0
for p in primes_below(100):
    total += p
    print(f"{p:3d} {total:5d}")

The same idea in C looks like this, with a fixed array of 1000 flags and a loop bound of 31, because 31 times 31 is 961, and the next prime, 37, squares to 1369, which is already beyond the end of the array.

#include <stdio.h>
#include <string.h>

int main(void) {
    static unsigned char composite[1000];
    memset(composite, 0, sizeof composite);
    for (int n = 2; n <= 31; ++n) {
        if (!composite[n]) {
            for (int m = n * n; m < 1000; m += n) composite[m] = 1;
        }
    }
    int count = 0;
    for (int n = 2; n < 1000; ++n) {
        if (!composite[n]) ++count;
    }
    printf("%d primes below 1000\n", count);
    return 0;
}

Here is a second program, this time in JavaScript, that counts the words in a block of text and prints the five most common ones along with how many times each occurs.

function topWords(text, limit = 5) {
  const counts = new Map();
  for (const word of text.toLowerCase().match(/[a-z']+/g) ?? []) {
    counts.set(word, (counts.get(word) ?? 0) + 1);
  }
  return [...counts.entries()]
    .sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]))
    .slice(0, limit);
}
